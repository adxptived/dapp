# 🏆 Dota Party

Android/iOS-приложение для пати Dota 2: рейтинг, оценка MMR и статистика ранкед-игр. Перенос всех функций
Telegram-бота [dota-party-tracker](https://github.com/adxptived/dota-party-tracker) в приложение. Данные — из
[OpenDota](https://www.opendota.com/) (и [Stratz](https://stratz.com/api) по ключу). Сервер не нужен: всё
считается и хранится на телефоне.

## Установка

1. Откройте [последний релиз](https://github.com/adxptived/dapp/releases/latest) и скачайте `dapp-1.0.N.apk`.
2. Установите (Android попросит разрешить установку из браузера/файлового менеджера).
3. Дальше обновления приходят сами: приложение проверяет релизы при запуске (и в фоне), скачивает APK и ставит
   **поверх** — удалять старую версию не нужно, данные сохраняются.

Для iPhone в релизе есть `dapp-unsigned.ipa` — неподписанная сборка для установки через AltStore/Sideloadly.

## Что умеет

| В боте | В приложении |
|---|---|
| `/add`, `/remove`, `/list`, `/setmmr`, `/me` | Настройки → Пати; карточка игрока → «Задать MMR», «Это я», переименовать, удалить |
| `/stats`, `/today` | **Рейтинг**: отчёт пати, таблица игроков (≈MMR, ±MMR, W–L, винрейт, KDA, форма, герои), периоды и сортировка; **Главная**: сегодня/неделя/месяц |
| `/player` | Карточка игрока: ≈MMR и динамика, KDA/GPM/урон/нетворс, перф, сила в пати, соло vs группа, лучший/худший час, топ-10 героев, последние игры с ±MMR, профиль скилла, журнал MMR |
| «📜 Матчи» | Все матчи игрока по страницам с фильтром по герою и исходу |
| `/match`, `/last` | Разбор матча: обе команды, K/D/A, нетворс, крипы, GPM/XPM, урон, предметы, IMP и позиции (Stratz), запрос разбора |
| `/find`, `/search`, `/id`, `/steam` | **Поиск**: матч или любой игрок по ID/ссылке (Dotabuff/OpenDota/Stratz/Steam, включая /id/…), «Добавить в пати» |
| `/compare`, `/table` | Сравнение: индекс «силы в пати» и места по перфу, винрейту, KDA, GPM |
| `/together` | Вместе: совместные игры, лучшая пара, матрица пар |
| `/heroes` | Герои: любимые пати, топ игрока, кто как играет на герое |
| `/matchups` | Соперники и союзники (сглаженный винрейт) |
| `/roles` | Позиции 1–5 (нужен ключ Stratz) |
| `/records` | Рекорды игр + лучшая серия, антирекорды |
| `/graph` | График MMR по времени или по номеру игры |
| `/achievements`, `/contest` | Соревнование: подиум, номинации с топ-3, антирекорды |
| `/season`, `/hall` | Сезоны (старт, досрочное завершение, автозакрытие с чемпионом) и зал славы |
| `/go` | «Позвать пати»: сообщение со временем, отметки «иду/позже/пас», отправка в Telegram |
| `/status` | Настройки → Состояние API: OpenDota/Stratz, остаток лимита, очередь |
| `/settings` | Шаг MMR, час сводки, уведомления, ключи, адрес OpenDota, период по умолчанию, длительность сезона |
| Оповещения, сводки | Уведомления: конец матча (±MMR), ежедневная сводка, итоги недели, смена лидера, смена ника/аватарки в Steam, конец сезона |
| Бэкап БД | Автокопия раз в день (7 штук), экспорт/импорт в файл |

Что осталось только в Telegram: inline-режим, теги участников чата и права админов — у приложения нет чата.

## Про MMR

Точный MMR не отдаёт ни один публичный API, поэтому он **оценивается**:
`MMR ≈ заданный MMR + (победы − поражения) × шаг` (шаг по умолчанию 25). Ранг, игры, KDA, винрейт, герои и GPM —
настоящие данные. Матчи видны, если в Dota 2 включена «Общедоступная история матчей».

## Сборка

Собирает GitHub Actions (`.github/workflows/build.yml`) на каждый пуш в `main`:

1. `flutter create .` дополняет недостающие платформенные файлы по актуальному шаблону Flutter;
2. `tool/patch_platforms.py` настраивает подпись, desugaring, разрешения, имя и иконку;
3. `flutter build apk --release` с номером сборки = номер запуска (растёт всегда — поэтому обновление ставится поверх);
4. APK публикуется в Releases с тегом `v1.0.N`; iOS-сборка без подписи — туда же.

Все APK подписываются одним ключом `signing/dapp-release.jks` (пароль — в `tool/patch_platforms.py`).
Ключ менять нельзя: APK с другой подписью Android поверх не поставит.

Локально: Flutter stable, затем те же шаги, что в workflow.
